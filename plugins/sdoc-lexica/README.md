# SDOC plugin for Claude Code

Teaches Claude Code to read, write and navigate [SDOC](https://github.com/entropicwarrior/sdoc) files and Lexica knowledge trees (`lexica/` directories), a section at a time.

- **Skills:** `/sdoc-lexica:authoring` covers the format, and `/sdoc-lexica:lexica` covers finding and maintaining project knowledge.
- **Tools:** `mcp__sdoc-lexica__list`, `outline`, `read`, `search`, `guides` and `check`. They are read-only and read only inside the project, where they run without a prompt.
- **Hooks:**
  - A knowledge index on the first prompt.
  - A file's reading guide on its first Read.
  - Its editing guide before its first edit.
  - The findings each edit adds.

It runs inside Claude Code as a mod, so no Node.js or other runtime is needed.

## Install

```
/plugin install sdoc-lexica --marketplace entropicwarrior/sdoc
```

Team rollout, requirements and how it is built: [docs/guide/claude-code-plugin.sdoc](https://github.com/entropicwarrior/sdoc/blob/main/docs/guide/claude-code-plugin.sdoc).

Settings (`/plugin configure sdoc-lexica@sdoc`):
- `indexSize`: how much the knowledge index may add to the first prompt, `6k`, `12k` (default) or `24k` characters.
- `verbose`: shows each thing the plugin does as a line in your session.

Everything under `lib/` and `skills/authoring/reference/` is generated by `npm run build:plugin` at the repository root. Edit the sources instead.
