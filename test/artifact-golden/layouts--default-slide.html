The default layout

A slide with no config: line is left-aligned and runs top to bottom. It is the layout every deck had before the structured ones existed, and it is unchanged.

  • Prose, lists and tables render as they always did
  • No child scope is consumed as structure
  • A nested scope is a nested scope, not a column
